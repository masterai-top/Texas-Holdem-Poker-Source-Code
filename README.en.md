### 🔥 Why Choose This Source Code?


This is a **battle-tested, comprehensive Texas Hold'em solution** that has been successfully operating in the market for years.
Unlike the cobbled-together demos often found elsewhere, our codebase undergoes continuous iteration and offers stable performance;
it is already being used by multiple clubs for live operations.


### ✨ Key Selling Points


-   **Comprehensive Game Suite**: Full support for Texas Hold'em, Omaha, Short Deck, Pineapple (OFC), MTT, SNG, AOF, and **League Mode**.

-   **Club & Private Games**: Complete features for game setup, club management, insurance mechanics, and detailed game statistics.

-   **High Stability**: High-performance C++ server architecture capable of handling thousands of concurrent players with ease.

-   **Premium Assets**: Includes a full set of high-definition art assets, UI source files, and sound effects.

-   **Competitive Edge**: Outperforms **hhpoker** and **wpk** across the board in terms of features, stability, and scalability.
### 🎯 Feature List


| Module | Feature Description |
| :--- | :--- |
| **Lobby System** | Access to multiple game modes, announcements, leaderboards, in-game store |
| **Private Games/Clubs** | Private games with friends, club creation/management, league tournaments |
| **Table Logic** | Standard/Short Deck/Omaha, auto buy-in, straddle, insurance |

| **Backend Management** | Player management, statistical reporting, game score adjustments, risk control |


### 🚀 Technical Architecture


-   **Server-side**: C++ (High efficiency and stability)
-   **Client-side**: Cocos Creator / Unity (Demo available)
-   **Communication**: Tars / Private protocol
-   **Data**: MySQL + Redis
